# 💅 Projeto Integrador Front-end — Espaço Bella Nails

Site institucional e catálogo interativo desenvolvido para a disciplina de **Desenvolvimento Front-end para Web**. O objetivo é apresentar os serviços oferecidos pelo estúdio **Espaço Bella Nails**, exibir a tabela de agendamento semanal, facilitar o contato com as clientes e fortalecer a presença digital do negócio.

---

## 🎯 Objetivo
Desenvolver uma página web semântica, acessível e responsiva que organize os serviços, horários e inspirações do **Espaço Bella Nails**, oferecendo uma experiência agradável em dispositivos móveis e desktop e integrando funcionalidades dinâmicas em JavaScript.

---

## ✨ Funcionalidades Implementadas
* **Navegação Responsiva:** Barra de navegação fixa (`position: sticky`) com Flexbox e submenu dropdown para categorias de serviços.
* **Catálogo e Galeria de Inspirações:** Grade responsiva construída com CSS Grid (`repeat(auto-fit, minmax(...))`) e fotos ajustadas com `object-fit: cover`.
* **Tabela de Agendamento Semanal:** Exibição organizada de dias, horários, profissionais, valores e disponibilidade.
* **Formulário com Integração WhatsApp:** Formulário semântico e acessível que envia os dados do pré-agendamento diretamente para o WhatsApp do estúdio.
* **Mídia e Elementos Gráficos:** Logotipo vetorial em SVG inline acessível, vídeo tour com fallback de formatos e gráfico de meta mensal desenhado via `<canvas>` 2D.
* **Análise de Dados em JavaScript:** Scripts puros (`logica.js` e `script.js`) utilizando `prompt`, condicionais, laços e métodos de array (`map`, `filter`, `reduce`) com renderização dinâmica no DOM.
* **Contato e Localização:** Cards de atendimento e mapa interativo incorporado.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Semântico e Acessível)
* **CSS3** (Variáveis `:root`, Flexbox, Grid, Box Model)
* **JavaScript** (ES6+, Manipulação de DOM e Canvas 2D)
* **Git & GitHub** (Versionamento com Conventional Commits e Pull Requests)
